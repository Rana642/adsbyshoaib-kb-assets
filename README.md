# adsbyshoaib-kb-assets

Public image mirror for the Ads by Shoaib knowledge base. Served through jsDelivr
(`https://cdn.jsdelivr.net/gh/Rana642/adsbyshoaib-kb-assets@<commit>/<path>`) because Claude web's
widget/artifact sandbox only loads images from a few CDNs.

- Structure: `<project-slug>/products|literature|assets/<name>.<ext>`
- Files are web renditions (≤1600 px) of brand product photos and brochure pages.
- **Public and permanent.** Only material that may be public is published here
  (via the `kb_publish_to_cdn` MCP tool, which requires explicit confirmation).
  Never put client-private files in this repo.
